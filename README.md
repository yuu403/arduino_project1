#  Arduino Portfolio

## 概要
Arduinoを用いた開発プロジェクトをまとめたポートフォリオです。  
**状態遷移・時間制御・センサ入力・リアルタイム可視化を統合した組み込みシステムを設計・実装**し、
基礎から応用まで段階的にスキルを習得しました。

IoT・スマートデバイスへの関心から、ソフトウェアだけでなくハードウェアを動かす技術を身につけたいと思い、Arduino を使った学習を始めました。

単純なLED制御から出発し、状態遷移・センサ入力・PWM制御へと段階的に複雑さを高めながら、最終的に **Pythonと連携したリアルタイム可視化システム** まで構築しています。「設計してから実装する」習慣を意識して取り組んでいます。

将来はエンジニアとして、現実の環境に作用するシステムを作ることを目標に、引き続き学習を進めています。

---
##  メインプロジェクト：光量自動調整信号機

### 光量自動調整信号機 + リアルタイム可視化（LED_08：最新版）

![demo](./LED_08/images/demo_light.gif)

フォトレジスタで周囲の明るさを検知し、LEDの輝度を環境に応じて自動制御する信号機システムです。  
さらに **Pythonと連携**し、センサ値・輝度・状態をリアルタイムでグラフ表示・CSV記録します。

**技術ポイント**

- 状態遷移（State Machine）による信号機制御
- `millis()` を用いたノンブロッキング処理
- フォトレジスタによるアナログ入力 → PWM制御（`analogWrite`）
- ローパスフィルタによる滑らかな輝度変化
- ArduinoとPythonのシリアル通信（115200bps）
- `matplotlib` によるリアルタイムグラフ表示
- CSVログ保存によるデータ分析

```
[光センサ]
     ↓
 Arduino（制御・PWM）
     ↓  Serial通信（115200bps）
 Python（可視化・記録）
     ↓
 リアルタイムグラフ + CSV保存
```

## 成果
- 複数状態（最大5状態）の信号機制御を実装
- 非ブロッキング処理により複数処理の同時実行を実現
- 入力（スイッチ）・出力（LED）・センサ（光）を統合したシステムを構築
- 環境光に応じたリアルタイム制御を実現

## 実行方法

### Arduino
- Arduino IDEをインストール
- 任意のプロジェクトフォルダ（例：LED_08）を開く
- ボードを「Arduino Uno」に設定
- COMポートを選択
- マイコンへ書き込み

### Python（LED_08のみ）

```bash
python LED_08.py
```
